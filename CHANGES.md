# Changes made while assembling this working Mark 1

These are the changes made while assembling this distribution from the private
development tree, recorded so the provenance of the published state is explicit.

## Boundary

- Assembled from the live tree, so this carries **Mark 1 identity and
  Qualification v2**. (The older `artifacts/joss-prepublic/` bundle predates
  both and was used only as a shape reference.)
- Excluded `apps/` and the loopback browser controller: it imports
  `yauvi_platform.oral_atlas` and `yauvi_platform.protein_case`, which are
  private. `yauvi_platform.structural_workbench` has no sibling imports and
  ships alone.
- Excluded `benchmarks/qualification-v1/{sources,build}` — 12 MB of wwPDB, OPM,
  CATH, AlphaFold and M-CSA records. `benchmark-manifest.yaml` declares
  `ships_public_records: false`, and now that is true. The source lock ships so
  a reviewer can acquire the exact checksummed artifacts.
- Excluded build residue, caches, `_archive/`, `_quarantine/`, and the module
  directories outside the declared distribution.

## Pruning caught on the final audit

The first assembly pass copied `tools/` and `examples/` wholesale, which pulled
in material that does not belong in a publication candidate. Removed:

- `tools/` reduced from 50+ scripts to the 10 this distribution actually uses.
  The discarded set included TDVax portal builders, `prepare_cloudflare_deploy.py`,
  `prepare_cloudflare_private_deploy.py`, and `yauvi_private_release.py`.
- `examples/oral-ecosystem/` and `examples/composition/` — private oral
  microbiome research, unrelated to the six structural workflows. Only
  `examples/structural-portfolio/`, which the showcase builder needs, remains.
- Build residue: `build/`, `dist/` intermediates, `*.egg-info/`.

`tools/build_cli_reference.py` also embedded the generating user's home
directory, because `yauvi-fetch --help` prints a default cache path under `~`.
The generator now scrubs `$HOME` before writing, so the reference reads
`~/.cache/yauvi/sources`.

## Correctness

- **memorient remediation message named a package that does not exist.** It told
  users to `pip install 'membrane-orientor[compute]'`; the distribution is
  `memorient`. The lazy-import guard itself was already correct — the earlier
  review characterised this as "unrunnable standalone", which was too strong.
  The defect was the unusable instruction, now fixed.
- **Qualification v2 exit code was unconditional `return 1`.** It now returns 0
  only when the panel is composed, 1 otherwise. It still cannot report a scope as
  qualified, and `scientific_execution_performed` stays false.
- **`HUC-06/release/CHECKSUMS.json` listed 21 files where 6 exist.** Regenerated
  against the files actually present. The 6 retained digests showed **no drift**,
  confirming the manifest was over-listing pruned files rather than recording
  corrupted ones.
- **Wheel verifier failed on setuptools < 77.** It required the newer
  `.dist-info/licenses/` layout. It now accepts either layout.

## Claim integrity

- **"FreeSASA 2.1.3" removed from all five prose sites.** The qualification
  evidence records only the binary path and method, never a version; the `2.1.3`
  string came from an unrelated synthetic run's capability banner. That banner is
  a genuine recorded artifact and was left in place.
- **Test counts corrected to this distribution's real numbers.** `BASELINE.json`
  regenerated from an actual run: **495 passed, 6 deselected, 1 skipped**, 11
  suites, no `apps/yauvi/tests` entry. The stale 524 was updated in
  `JOSS_CHECKLIST.md` and `PREPUBLIC_AUDIT.md`.
- **The unbacked 471/10/5 cross-platform figure is no longer quoted as evidence.**
  No `TEST_RESULT.json` was ever committed and `RELEASE_STATUS.json` records both
  install matrices as not passed; the text now says so instead of citing counts.
- **`START_HERE.md` no longer reports only the favourable v1 result.** It now
  states the current gate: Qualification v2 is `blocked_panel_incomplete`, 0 of
  114 cases adopted.

## Packaging

- Removed `jsonschema` from the root dependencies — nothing in this distribution
  imports it.
- `memorient` `requires-python` raised from `>=3.9` to `>=3.10`, matching every
  sibling and the tested CI matrix.
- Added `LICENSE` to all nine module directories, so standalone wheels are no
  longer license-less.
- Filled the Apache-2.0 appendix placeholder: `Copyright 2026 Yuvraj Patel`.
- `CITATION.cff`: version aligned to `0.1.0.dev0`, affiliation added, and the
  dangling `repository-code` URL removed until a repository actually exists.

## Documentation

- **Added `docs/cli-reference.md`** — 43 documented subcommands across all nine
  CLIs, generated by the new `tools/build_cli_reference.py` from each parser's
  own `--help`, so it cannot drift. `--check` fails if it goes stale, and CI runs
  that check.
- **Replaced the GUI-only quickstart with a runnable CLI walkthrough.** Every
  command in it was executed and its stated outputs verified, including the
  determinism diff and the fail-closed exit `1`.
- **One install command everywhere:** `pip install -e ".[dev]"`. The broken
  `pip install -e "yauvi-structural-workbench[dev]"` is gone.
- `docs/reproducibility.md` no longer recommends bare `pytest`, which the
  project's own docs say does not work; it points at the authoritative runner.
- GUI start commands removed from README, `START_HERE.md`, `install.md`,
  `reviewer-quickstart.md`, `cross-platform-testing.md`, `reproducibility.md`,
  and `PLATFORM_IDENTITY.json`, and both showcases were regenerated.

## Tooling and CI

- `tools/run_structural_workbench_tests.py`: dropped the excluded controller
  suite, added the Qualification v2 suite.
- `.github/workflows/structural-workbench.yml`: removed `apps/` references and
  added the CLI-reference drift check. The workflow has still **never run** —
  there is no repository.

## Not addressed here

Requires decisions or scientific work, not edits: the absent repository, the
114 unexecuted Qualification v2 cases, community contact channels, the paper's
self-disqualifying impact statement, COI/funding/AI-disclosure approval, the
ActState labelling and SF-CSA reciprocal-best-hit ordering defects, and an
automated independent digest-verification test.
