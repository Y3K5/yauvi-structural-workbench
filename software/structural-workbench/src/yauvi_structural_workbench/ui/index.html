How to read this evidence
A completed execution means the software finished. Scientific qualification and independent reproduction are separate checks. An incomplete result identifies missing evidence; it does not establish the missing biological conclusion.
Checksums identify exact file contents. The run manifest records inputs, parameters and software identities. The full evidence bundle preserves the underlying records.

A guide to the workbench
Begin with Explore the guided showcase to see real protein examples, or Try an offline example to practice running an analysis.
  1. Inputs: the files and references your question needs.
  2. Process: what the software is doing.
  3. Findings: measurements with their interpretation limits.
  4. Evidence: the exact inputs and methods behind a result, plus a report you can save.
Protein structure
A three-dimensional arrangement of a protein’s atoms.
Residue
One amino acid in the protein chain.
Reference
A comparison structure or supporting record. Its identity and source matter.
Ready to run
The required files and tools are available. It does not guarantee a biological conclusion.
Evidence incomplete
The analysis finished but some information is missing. The gap is part of the result.
Provenance
A record of where the input came from and how the result was produced.
Checksum
A file fingerprint used to detect whether its contents changed.
The software helps inspect evidence. A completed run is not proof of biological activity or experimental validation.
