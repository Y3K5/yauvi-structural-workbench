# Scientific protocols for the changed workbench

These six protocol records snapshot the existing qualification manifest without
changing its thresholds, expected cases or exclusions. They are preparation
records, awaiting human and independent scientific review; their creation does
not authorize remeasurement or make new results qualified.

The manifest and source lock remain canonical in `../benchmarks/qualification-v2/`.
The `frozen_panel` field retains each full panel, including reference standards
and inclusion rules. `missing_evidence_controls` defines the next proposed
scientific work. Review each protocol before reading newly measured results.
No recorded historical evidence has been replaced.
