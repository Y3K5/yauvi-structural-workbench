# Support

For installation and scientific-use questions, begin with the documentation in
`docs/`. A future public repository will use GitHub Issues for reproducible bugs
and Discussions for usage questions.

Treat silent scientific corruption—wrong residue identity, mismatched checksum,
permissive missing-evidence behavior, or widened claims—as a high-severity issue.
Do not attach unpublished sequences, private coordinates, credentials, or local
omics data to a public report.
