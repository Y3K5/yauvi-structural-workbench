Your first 20 minutes

  1. Open the showcase. Without reading technical commands, explain what one tool helps you understand.
  2. In Conformational state, select the DFG motif and an amino acid. Use the slider, then explain the difference between the two measured shapes and the illustrated motion.
  3. In Cross-proteome comparison, find the two species and one research citation. Explain why similar shapes do not automatically mean identical function.
  4. Find an explicit limitation or missing piece of evidence. Describe it in your own words.
  5. Try a narrow window and keyboard navigation. Tell us where you lose track of the next action.

We are testing clarity and usability. Correctly explaining an uncertainty is a successful outcome; making every result look positive is not the goal.

Install the full workbench

  1. Extract the entire ZIP into a normal local folder. Do not launch inside the ZIP.
  2. Open Launch Mac.command on macOS, Launch Windows.cmd on Windows, or run sh "Launch Linux.sh" on Linux. If Python is not installed, use the installation-free showcase or ask the facilitator to install Python 3.12.
  3. The launcher asks before its first dependency download. Type y only when ready. Setup may take several minutes. Subsequent launches reuse the environment.
  4. Your browser opens the local workbench. Keep the launcher window open while testing. Use Try an offline example, then Check readiness and Run analysis.
  5. Find a measurement in Findings. Open Evidence to save and reopen its report. Repeat with Leave out validation evidence selected and describe the missing evidence.

Your analyses are stored in a separate YAUVI Tester Library folder in your home directory. They are not included in this kit. Use only the supplied synthetic example or reviewed public test data.

If the launcher does not open

You can run python3 start_workbench.py (macOS/Linux) or py -3 start_workbench.py (Windows) from the extracted folder. If macOS or organizational policy blocks a downloaded launcher, ask your facilitator for help; the offline showcase remains available. A different app on port 8962, a missing Python installation, or a dependency download failure will require setup assistance. Do not disable security controls.

The package contains application code, not a bundled Python interpreter or a signed desktop installer. Fresh installation on Windows and Linux remains unverified. The launcher binds only to 127.0.0.1 and does not upload protein files.
